# Chartworks skills

Agent skills for [Chartworks](https://chartworks.dev): chart rendering for AI agents.

```bash
npx skills add chartworks/chartworks --skill chartworks -g
```

Other install options, and MCP for chat apps: [chartworks.dev/docs/connect](https://chartworks.dev/docs/connect).

Issues: [github.com/chartworks/chartworks/issues](https://github.com/chartworks/chartworks/issues). License: MIT.
